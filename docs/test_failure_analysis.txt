Root Cause 2: Async Propagation Race Conditions
The test uses waitForPropagation(800) — an 800ms fixed delay:
async function waitForPropagation(ms = 500) {  await new Promise((r) => setTimeout(r, ms));}
Problem: 800ms may not be enough for full propagation in a loaded test environment. The onEventUpserted function is fire-and-forget (no await on the propagation call in the webhook handler).
Fix — Replace fixed delay with polling:
async function waitForPropagation(maxMs = 5000, pollInterval = 200) {  const start = Date.now();  await new Promise((r) => setTimeout(r, 300)); // Minimum wait  // Caller should poll for expected state instead of blind wait}// Better: poll for shadow blocksasync function waitForShadowBlocks(  eventId: string,  expectedMinCount: number = 0,  maxWaitMs: number = 5000): Promise<any[]> {  const start = Date.now();  while (Date.now() - start < maxWaitMs) {    const blocks = await getShadowBlocksForEvent(eventId);    if (blocks.length >= expectedMinCount) return blocks;    await new Promise((r) => setTimeout(r, 200));  }  return await getShadowBlocksForEvent(eventId);}
Root Cause 3: onEventUpserted Import Path
The test imports directly from ./services/eventPropagation:
import { onEventUpserted, onEventDeleted } from "./services/eventPropagation";
But eventPropagation.ts is at /mnt/agents/work/Geeves/eventPropagation.ts (root level), not in a services/ subdirectory. The correct import depends on the beta sandbox’s directory structure.
Possible fix paths: - If eventPropagation is at server/services/eventPropagation.ts: import from "./server/services/eventPropagation" - If eventPropagation is at root alongside the test: import from "./eventPropagation"
